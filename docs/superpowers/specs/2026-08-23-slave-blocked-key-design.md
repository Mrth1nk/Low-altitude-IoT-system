# 从机 B 键光路阻断预览设计

## 目标

在本机地面站中按住键盘 `B` 时，从机控制页面临时呈现与主机一致的光路阻断状态；松开按键后立即恢复涂鸦云返回的真实状态。

## 交互

- 按住 `B`：仅从机页面显示 `BLOCKED` 和 `OPTICAL LINK BLOCKED`，从机指令按钮临时禁用。
- 松开 `B`：清除预览，重新渲染最近一次云端状态。
- 浏览器窗口失焦或页面进入后台：自动清除预览，防止按键状态粘滞。
- 输入框、文本域和可编辑区域内输入 `B` 不触发预览。
- 小车 `WASD` 连续控制保持原样。

## 边界

该功能完全位于浏览器前端，不写入涂鸦属性，不发送 MAVLink 指令，也不修改主机、从机或 RDK 服务。真实光路阻断仍由原有云端状态控制。

## 验证

- 自动测试覆盖按下、松开、失焦恢复和可编辑区域忽略行为。
- 运行完整地面站测试，确认既有指令、状态合并和键盘控制测试不回归。
